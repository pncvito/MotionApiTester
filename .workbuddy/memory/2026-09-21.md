### 已确认缺陷（截至本次审核均未修复）
- **接口方法必然调用失败**：`ApiInvoker` 用 `DeclaringType`（接口）做 `Activator.CreateInstance` → `MissingMethodException: 无法创建接口的实例`（history.json 中 `IBaseInterface.InitializeFixture` 有两条实证）。
- **构造函数永远枚举不到**：`ReflectionEnumerator` 用 `type.GetMethods()`，该方法不返回 ctor → `ApiType.Constructors` 恒空，`#ctor` 分支与 UI"构造函数"分组都是死代码。
- **属性/字段 get 分支不可达**：`InvokeCommand.CanExecute` 要求 `SelectedMethod != null`，选中属性/字段时"调用方法"按钮始终禁用。
- **两处死输入**：`ApiParameter.PassNull`（传 null 勾选框）与 `TbJsonArgs`/`JsonArgsOverride`（高级 JSON 数组）都无任何消费方。
- **原生 DLL 视图 + 设备管理只有后端没界面**：XAML 中零引用 `CurrentView`/`NativeDlls`/`PInvokeTemplate`/`Devices`/`SelectedDevice`；「⚙ 原生 DLL」按钮点击无反应，`DeviceWizardWindow` 无法打开。
- **深色主题失效**：XAML 硬编码 `#DFF6DD`/`#FAFAFA`/`#24292F`，`UpdateResultCardStyle` 也写死颜色；主题里 `TagPublic/Static/Instance/LoggerBrush` 零引用。启动时 `ApplyTheme()` 依赖 `Application.Current.MainWindow`，而 VM 在 Window 构造期实例化（此时仍为 null）→ 已保存的 Dark 主题不会在启动时生效。
- **树选中高亮失效**：`Window.Resources` 里的隐式 `TreeViewItem` 样式被 `TreeView.ItemContainerStyle`（未 `BasedOn`）覆盖，`RowSelectedBrush` 左蓝边永不显示。
- **取消无效**：`Task.Run` 的 token 无法中断正在执行的同步反射调用。
- **卸载是假的**：`Assembly.Load/LoadFrom` 不可卸载，`_assemblyByteCache` 不清理，仅清 UI。
- **历史**：`HistoryService.Load` 用 `Insert(0)` 反序插入，重启后顺序反转；"按设备隔离"是假的（deviceId 硬编码 `"default"`）。
- **搜索性能**：每次按键全量重建树，且先构建全部成员再 `PruneTree` 丢弃；`BuildTypeNode` 的 `isSearchFilter` 恒为 false → 该段过滤逻辑是死代码。
- 其他：`DeviceBinDir` 硬编码未用 `AppSettings.DefaultDeviceDirectory`；`DeviceManager.AddDevice` 无重复校验；大量 `catch {}` 静默；`AssemblyLoader`/`LogService`/`CopyToTemp`/`ApiInvoker.OnLog`/`_dispatcher`/6 个转换器均为死代码。
- 界面结构：`MainWindow` 用 6 行 Grid + 覆盖式叠层（主内容 `Grid.Row=2` `RowSpan=3` `Margin="0,28,0,23"`），并自造伪标题栏（`Title=" "` + 三个不可点击圆点）叠在系统标题栏之下。
